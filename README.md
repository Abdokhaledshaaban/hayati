# حياتي — الروتين + المهام في موقع واحد

موقع ثابت (بدون سيرفر): لوحة تحكم، جدول أسبوعي، مهام، ملاحظات. كل البيانات في متصفحك (localStorage).

## النشر على GitHub Pages
1. ارفع كل الملفات (`index.html` و`style.css` و`app.js` و`sw.js` و`manifest.json` و`icon.svg` و`README.md`) في ريبو.
2. Settings → Pages → Branch: `main` / root → Save.
3. افتح الرابط، ومن المتصفح اختار «إضافة للشاشة الرئيسية» عشان يشتغل كتطبيق.

أول فتح بعد التحديث بيستبدل الجدول بالمواعيد الجديدة مرة واحدة (المهام والملاحظات والعادات بتفضل زي ما هي).

نسخة احتياطية: زر ⬇ للتصدير و⬆ للاستيراد.
